# 🎙️ Real-Time Voice Assistant using Next.js

> **🚀 Transform your browser into a smart voice-powered assistant!**

## 🌟 Overview
This **Real-Time Voice Assistant** is built with **Next.js**, featuring real-time **speech recognition** and **AI-powered responses**. The assistant continuously listens for voice commands and executes tasks accordingly.

## 🛠 Features
✅ **🎤 Real-time voice recognition**  
✅ **🔊 Text-to-speech AI responses**  
✅ **🎯 Trigger-based execution** (e.g., *"AI, start recording"*)  
✅ **🤖 Integrated with Gemini AI API**  
✅ **🌐 Works in-browser with Web Speech API**  
✅ **🎨 Modern UI with Tailwind CSS**  

## 📦 Tech Stack
🚀 **Next.js** - The React framework  
🗣️ **Web Speech API** - Voice recognition & synthesis  
🤖 **Gemini AI API** - AI-driven response processing  
🎨 **Tailwind CSS** - Sleek and responsive UI  

## 🚀 Installation & Setup
```sh
# Clone the repository
git clone https://github.com/yourusername/real-time-voice-assistant.git
cd real-time-voice-assistant

# Install dependencies
yarn install  # or npm install

# Run the development server
yarn dev  # or npm run dev
```

## 🎯 Usage Guide
1. Open the web app in your browser.
2. Say **"AI"** to activate the assistant.
3. Speak a command, such as *"AI, what's the weather today?"*
4. The assistant will process and respond instantly.
